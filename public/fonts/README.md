# Fonts

`bb-heros-regular.woff2` and `bb-heros-bold.woff2` are Latin subsets of **TeX Gyre Heros** (regular and bold), a Helvetica-style typeface by the GUST e-foundry. Source: CTAN, `fonts/tex-gyre/opentype/`.

They load only on devices without Helvetica Neue (Android, Windows). See `src/app/globals.css`.
